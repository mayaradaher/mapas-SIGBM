## Automatic Monitoring of Flood Maps in SIGBM

This application is an automated system that daily checks for the inclusion of new Flood Maps on the site of the [Integrated Mining Dam Management System - SIGBM](https://app.anm.gov.br/SIGBM/Publico/GerenciarPublico) of the Brazilian National Mining Agency's (ANM). When a new map is detected, the application automatically sends an email alert to registered users, ensuring that stakeholders are promptly informed about the update.
